## CENTINELA 4.0 ##

La nueva generación de Centinela orientada a DevSecOps, automatización y escalabilidad.

Actualmente se encuentra en etapa temprana de desarrollo y toma como base los aprendizajes obtenidos durante la construcción de Centinela 3.0.

## Objetivos

* Mejorar la modularidad del código.
* Separar responsabilidades por componentes.
* Facilitar pruebas y mantenimiento.
* Incorporar nuevas capacidades de automatización.
* Preparar la integración futura con servicios cloud y mecanismos avanzados de análisis.

## Arquitectura actual

Estructura inicial implementada:

* Configuración centralizada.
* Variables de entorno.
* Docker.
* PostgreSQL.
* Organización modular.
* Gestión de dependencias.

## Stack tecnológico

* Python
* PostgreSQL
* Docker
* GitHub Actions
* AWS
* Linux
